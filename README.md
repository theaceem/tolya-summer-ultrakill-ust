# Толя Саммер UST

Набор кастомных саундтреков (UST) для [ULTRAKILL](https://store.steampowered.com/app/1229490/ULTRAKILL/) на основе музыки Толи Саммера.

> ⚠️ Неофициальный мод. Проект не связан с New Blood Interactive и Hakita.

## Requirements

- ULTRAKILL (Steam)
- [BepInEx](https://github.com/BepInEx/BepInEx/releases) (актуальная версия)
- UST Manager

## Установка

1. Установи BepInEx и UST Manager, если они ещё не установлены.
2. Скачай архив с UST на странице [Releases](../../releases).
3. Распакуй архив и закинь папку с UST в папку `My USTs`.
4. Запусти игру и выбери этот UST в UST Manager.

## Авторство

Вся музыка принадлежит Толе Саммеру. Этот репозиторий только собирает её в набор для ULTRAKILL и не претендует на авторские права на треки.
